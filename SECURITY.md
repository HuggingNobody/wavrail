# Security policy

wavrail is a research-grade streaming speech recognition toolkit. It
ships with a synthetic-data acoustic model intended only for
demonstration. Production deployments must evaluate the toolchain
independently.

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting vulnerabilities

Email `236322002+StarWorkshop@users.noreply.github.com` with the
following information:

- A description of the vulnerability and its impact.
- Steps to reproduce, including any synthetic data needed.
- The wavrail version and Python version in use.

Please do not file a public issue for security problems. We aim to
acknowledge new reports within five working days.
